# core/tuning

Style presets (`StylePreset`, `StyleDefaults`): the defaults that differ between pop, classical, jazz/blues and gamaka-based singing (correction tolerance, glissando constant, blue-note handling, ornament handling). Plain data; layer 1 so tools (layer 5) can read it without linking analysis. Only `pop` is checked against recordings (`provisional = false`); the other rows come from the studies cited in `docs/design/note-pitch-target.md` and are provisional until the style-presets design note and listening sessions. 

`ChromaticGrid{Hz a4_reference}` and `target_pitch(Cents, grid)` (Phase 4, ADR-0016): the nearest 12-tone equal-temperament pitch on the absolute-cents axis; ties round toward +infinity; a 432 Hz reference moves every grid point by `1200*log2(432/440)` cents. `invalid_argument` for a non-finite pitch or an `a4_reference` that is not finite and > 0. Pure, thread-safe, real-time safe. It is the spec's `snap_chromatic` under its ADR-0016 name. Key, scale and curve grids (and the grid variant) come with Correct Pitch in Phase 6.
